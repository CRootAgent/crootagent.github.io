Mengapa Memilih CRootAgent?

Dirancang khusus untuk pengembang yang menuntut kecepatan, keamanan, dan efisiensi.

⚡

Ultra-Ringan (Rust Native)

Binary mandiri berukuran ringkas. Penggunaan memori ~10 MB saat standby, jauh lebih efisien dibanding agen berbasis Node.js atau Python yang menyerap 150–300 MB RAM.

🌐

Multi-API Session

Dukungan penuh untuk Google Gemini, Anthropic Claude, OpenAI, Groq Cloud, dan Ollama lokal. Beralih model dan provider kapan saja tanpa kehilangan konteks percakapan.

🛡️

Human-in-the-Loop (HITL) Safety

Setiap tindakan bedah (mengubah berkas atau mengeksekusi perintah terminal) meminta persetujuan pengguna secara eksplisit sebelum dijalankan.

🔧

Developer Tools Lengkap

Dilengkapi perkakas ReAct bawaan: read_file (dengan nomor baris), write_file, edit_file (surgical patch), run_command, dan list_dir.

💾

Penyimpanan Sesi Persisten

Setiap sesi percakapan otomatis tersimpan di mesin lokal. Anda dapat membuat sesi baru, melanjutkan sesi lama, atau mengekspornya ke format Markdown.

🚀

Multi-OS CI/CD Pipeline

Otomatisasi pengujian dan pembangunan berkas rilis untuk Linux x86_64, macOS Apple Silicon (arm64), macOS Intel, dan Windows x86_64 dengan GitHub Actions.

Cara Instalasi

Pilih metode instalasi yang paling sesuai dengan lingkungan kerja Anda.

🍎 macOS & 🐧 Linux (Skrip Otomatis)

Jalankan perintah ini di terminal Anda untuk mengunduh dan memasang binary terbaru secara otomatis:

curl -fsSL https://crootagent.github.io/install.sh | bash

🪟 Windows (PowerShell)

Buka PowerShell dan jalankan perintah satu baris berikut:

irm https://crootagent.github.io/install.ps1 | iex

🦀 Cargo (Rust Toolchain)

Bagi pengguna yang telah memiliki toolchain Rust/Cargo:

cargo install --git https://github.com/CRootAgent/crootagent.git

Panduan Pemakaian CLI

Perintah dasar untuk menjalankan CRootAgent di terminal harian Anda.

1. Konfigurasi Kunci API

Atur API Key provider pilihan Anda (atau gunakan environment variable):

# Konfigurasi via CLI
crootagent config set default_provider groq
crootagent config set groq_api_key "gsk_..."

# Atau via Environment Variable
export GEMINI_API_KEY="AIzaSy..."
export OPENAI_API_KEY="sk-..."

2. Jalankan Mode Interaktif (REPL)

Mulai sesi percakapan coding interaktif:

crootagent

# Di dalam REPL:
crootagent> Buatkan file scraper.py dengan BeautifulSoup
crootagent> /provider anthropic
crootagent> /export

3. Mode One-Shot (Eksekusi Instan)

Perintahkan agen untuk menyelesaikan satu tugas langsung dari terminal:

crootagent "Periksa file main.rs dan cari potensi bug memory leak"

# Otomatis konfirmasi perkakas (tanpa prompt tanya jawab)
crootagent -y "Jalankan cargo test dan jelaskan hasilnya"

4. Manajemen Sesi

Kelola riwayat sesi percakapan Anda:

# Lihat semua sesi
crootagent session list

# Lanjutkan sesi tertentu
crootagent --session <SESSION_ID>

# Hapus sesi lama
crootagent session delete <SESSION_ID>
